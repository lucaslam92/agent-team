# Semantic Store

This directory stores structured semantic knowledge and graph artifacts.

## Boundary

- Use `semantic-store/generated/` for machine-generated candidates and intermediate reports.
- Use `semantic-store/normalized/` for approved semantic cards.
- Use `semantic-store/index/` for graph indexes.
- Use `semantic-store/state/` for accumulation state and promotion state.
- Do not use this directory for long prose documentation; keep that in `knowledge/`.
