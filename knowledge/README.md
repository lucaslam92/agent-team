# Knowledge

This directory stores long-lived human-readable knowledge.

## Boundary

- Use `knowledge/` for business context, architecture guidance, rules, ADRs, and playbooks.
- Use `semantic-store/` for structured semantic cards, graph indexes, generated candidates, and accumulation state.
- Use `artifacts/` for current mission inputs and outputs.
