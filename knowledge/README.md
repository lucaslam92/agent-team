# Knowledge

本目录存放长期的人类可读知识，不存放结构化语义索引或机器候选产物。

## Boundary

- `knowledge/`：业务背景、架构说明、规则、ADR、playbook
- `semantic-store/`：结构化语义卡片、graph index、generated candidates、state
- `artifacts/`：当前任务输入输出
